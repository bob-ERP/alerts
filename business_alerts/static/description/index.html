Business Alerts

Why This Module Exists

This module enables sending alerts to n8n from Odoo, allowing for automated notifications and integrations with external workflows. It is designed for technical users who need to trigger external processes based on Odoo events. The module is intended to streamline alerting and automation tasks.

Set-up / Configuration

  • Assign appropriate security groups as defined in security/groups.xml.
  • Configure alert scenarios in the module's settings.
  • Review and adjust scheduled actions in data/cron.xml if needed.

Functionalities

  • Sends alerts from Odoo to n8n for further processing or integration.
  • Supports configuration of custom alert scenarios.
  • Includes security and access control for alert management.
